# Tazama Technical Steering Committee (TSC)

The TSC is the technical governing body of [Tazama](https://tazama.org), an open-source, real-time transaction monitoring platform for fraud and money laundering detection. Tazama is hosted by [LF Charities](https://lfcharities.org/).

This repository is the home for TSC governance documents, meeting records, proposals, and processes. If you want to understand how Tazama's technical direction is set, or how to get involved, you're in the right place.

## What the TSC Does

The TSC is responsible for all technical oversight of the Tazama project, including:

- Setting the technical direction and maintaining technical requirements
- Approving project and system proposals (incubation, deprecation, etc.)
- Organizing sub-projects and working groups
- Establishing community norms, workflows, and contribution policies
- Managing the release process and security issue reporting
- Creating and archiving repositories under the [tazama-lf](https://github.com/tazama-lf) organization

The full scope of TSC authority is defined in the [Technical Charter](CHARTER.md).

## Get Involved

There are several ways to participate in the Tazama community and TSC:

**Join the conversation.** The Tazama community communicates via Slack and a mailing list. These are the best places to ask questions, introduce yourself, or follow along with development.

- Slack: https://slack.tazama.org
- Mailing list: https://lists.tazama.org/g/TSC

**Contribute to the project.** Tazama is under active development and welcomes contributors. See the [Contributing Guide](https://github.com/frmscoe/.github/blob/main/CONTRIBUTING.md) and the [Documentation](https://github.com/tazama-lf/docs) repo for how to get started.

**Participate in GitHub Discussions.** Use the [Discussions](../../discussions) tab on this repo for Q&A, early-stage ideas, and community updates.
